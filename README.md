SISTEMA DE CADASTRO DE BIBLIOTECA

Projeto desenvolvido em Python como parte de um desafio prático no curso de programação na Escola de Programação Web para Meninas e Mulheres GRACE ICMC/USP.

SOBRE O PROJETO:

O Sistema de Cadastro de Biblioteca permite gerenciar um catálogo de livros, realizando operações de cadastro, consulta, empréstimo, devolução e remoção de livros.
Os dados são armazenados em um arquivo JSON, permitindo que as informações permaneçam salvas mesmo após o encerramento do programa.

FUNCIONALIDADES:

* Cadastro de livros, com título, autor e ano de publicação.
* Listagem dos livros cadastrados.
* Busca de livros por título ou autor.
* Empréstimo de livros disponíveis.
* Registro da devolução de livros.
* Remoção de livros do catálogo.
* Contagem de livros disponíveis e emprestados.
* Ordenação dos livros por título ou ano de publicação.
* Armazenamento e recuperação dos dados por meio de arquivo JSON.
